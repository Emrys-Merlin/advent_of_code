## Structure

- [`examples`](./examples) contains the examples as separate files. The file names follow the format `day{day:02d}_{counter:02d}.txt`
- [`inputs`](./inputs) the same for the inputs, but without the counter, i.e., `day{day:02d}.txt`.
- The other directories are named after a programming language and contain the solutions to AoC in that programming language. This year, there is at least a [`python`](./python) directory. The READMEs in each directory tell you how to run the solutions.
